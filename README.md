# Aws-S3-Static-website

AWS S3 Static Website Hosting with Server Access Logging
Project Overview
This project demonstrates how to deploy and host a static website using Amazon S3 Static Website Hosting and monitor website requests using S3 Server Access Logging.

The project uses two separate S3 buckets:
- Website Bucket: Stores website files and hosts the static website.
- Logging Bucket: Collects and stores server access logs generated by the website bucket.
The main objective is to uncraderstand static website deployment, S3 bucket configuration, public access permissions, and website access monitoring.
